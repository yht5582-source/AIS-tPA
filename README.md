# 急性缺血性腦中風 (AIS) 雙軌決策支援系統

## 📝 專案簡介
這是一個專為神經內科與急診醫師設計的單頁式 Web 應用程式 (Single-Page Application)。旨在協助醫療團隊在面對急性缺血性腦中風 (Acute Ischemic Stroke, AIS) 病患時，能快速、精確地進行「靜脈血栓溶解劑 (IV tPA)」與「動脈取栓 (EVT)」的雙軌評估與劑量精算，藉此縮短 Door-to-Needle 與 Door-to-Puncture 時間。

## ✨ 核心功能
* **自動黃金時窗計算**：輸入「最後正常時間 (LKW)」與「現在時間」，自動換算發病時數。
* **雙軌並行決策樹**：獨立且同步評估 IV tPA 與 EVT 資格，支援 Bridging Therapy 決策，並以顏色視覺化呈現四種處置情境。
* **動態禁忌症檢核**：將複雜的指引文字轉化為直覺的檢核表，觸發絕對禁忌症時自動中斷對應之治療路徑。
* **防呆劑量精算機**：內建 tPA 劑量公式 (0.9 mg/kg, Max 90mg)，自動算出推注 (Bolus) 與點滴 (Infusion) 劑量，並特別標示**廢棄量 (Waste)**，防堵臨床給藥過量的致命錯誤。

## 🏥 臨床邏輯依據
本系統邏輯參考以下指引建置（註：請依據院內最新規範與臨床狀況微調參數）：
* AHA/ASA 急性缺血性腦中風早期處置指引
* 台灣腦中風學會 (TSS) 治療指引

## 🚀 部署與使用方式
本系統採用純前端架構 (HTML + CSS + Vanilla JavaScript)，無須後端伺服器或資料庫即可運行。

1. **本機測試**：將原始碼儲存為 `index.html`，雙擊檔案即可在任何瀏覽器（Chrome, Edge, Safari）中開啟。
2. **雲端上線**：推薦將此單頁應用程式推送至您的 GitHub Repository，並直接開啟 **GitHub Pages** 功能進行代管。這能讓團隊在急診室或病房直接透過手機、平板快速存取工具。
