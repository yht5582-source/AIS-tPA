# 急性缺血性腦中風 (AIS) 雙軌決策與風險評估系統

## 📝 專案簡介
這是一個專為神經內科與急診醫師設計的單頁式 Web 應用程式 (Single-Page Application)。旨在協助醫療團隊在面對急性缺血性腦中風 (Acute Ischemic Stroke, AIS) 病患時，能快速進行「靜脈血栓溶解劑 (IV tPA)」與「動脈取栓 (EVT)」的雙軌評估。

本系統不僅整合了急症時窗與禁忌症檢核，更內建了神經學與慢性風險量表，幫助醫師在急診高壓環境下快速完成全面性的臨床決策。

## ✨ 核心功能 (Core Features)
* **雙軌並行決策樹**：獨立且同步評估 IV tPA 與 EVT 資格，支援 Bridging Therapy 決策，並以顏色視覺化呈現四種處置情境。
* **內建互動式臨床量表 (Live Calculators)**：
  * **NIHSS 神經學評分**：展開式下拉選單，點擊即時加總總分。
  * **CHA2DS2-VASc 中風風險評估**：用於非急症再灌注病患的後續抗凝血用藥評估。
  * **HAS-BLED 出血風險評估**：同步評估慢性抗凝血治療的出血風險。
* **動態 CT ASPECTS 判定**：直接輸入放射科報告分數，系統自動判定是否低於 6 分（大範圍梗塞）並連動 EVT 決策。
* **防呆劑量精算機**：內建 tPA 劑量公式 (0.9 mg/kg, Max 90mg)，自動算出推注 (Bolus) 與點滴 (Infusion) 劑量，並特別標示**廢棄量 (Waste)**，防堵臨床給藥過量。

## 🏥 臨床邏輯依據
本系統邏輯參考以下指引建置（註：請依據院內最新規範與臨床狀況微調參數）：
* AHA/ASA 急性缺血性腦中風早期處置指引
* 台灣腦中風學會 (TSS) 治療指引

## 🚀 部署與使用方式
本系統採用純前端架構 (HTML + CSS + Vanilla JavaScript)，無須後端伺服器或資料庫即可運行。

1. **本機測試**：將原始碼儲存為 `index.html`，雙擊檔案即可在任何瀏覽器中開啟。
2. **雲端上線 (推薦)**：您可以將此單頁應用程式推送至您的 GitHub 專案庫（Repositories），並直接啟用 **GitHub Pages** 功能進行代管，方便臨床團隊隨時透過行動裝置存取。
